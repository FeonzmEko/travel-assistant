## 二、当前遗留问题

### 2.1 行程详情页地图未真正展示

| 项目 | 说明 |
|------|------|
| 现状 | `TripDetail.tsx` 导入了 `AMapView` 并生成 `allSpots`，但页面没有渲染地图；同时活动数据里没有经纬度，只能生成 `0,0` 坐标 |
| 影响 | 行程详情页暂时无法展示路线地图，`R-02` 在行程详情场景下不完整 |
| 建议 | 在行程活动模型中保存景点经纬度，或根据景点名称二次查询坐标；然后在 `TripDetail.tsx` 中渲染 `AMapView` |
| 涉及文件 | `frontend/src/pages/TripDetail.tsx`、`backend/schemas/trip.py`、`backend/models/trip.py` |

### 2.2 前端构建可能被未使用变量阻断

| 项目 | 说明 |
|------|------|
| 现状 | `frontend/tsconfig.json` 开启了 `noUnusedLocals` 和 `noUnusedParameters`；`TripDetail.tsx` 中存在未使用的 `AMapView`、`allSpots` 等代码 |
| 影响 | `npm run build` 可能因为 TypeScript 未使用变量检查失败 |
| 建议 | 要么补齐地图展示逻辑，要么先删除未使用导入和变量 |
| 涉及文件 | `frontend/src/pages/TripDetail.tsx`、`frontend/tsconfig.json` |

### 2.3 地图安全密钥配置不完整

| 项目 | 说明 |
|------|------|
| 现状 | `AMapView.tsx` 使用 `VITE_AMAP_KEY` 加载高德地图，但 `window._AMapSecurityConfig.securityJsCode` 目前为空字符串 |
| 影响 | 如果高德控制台启用了 JS API 安全密钥，线上或本地浏览器可能无法正常加载地图 |
| 建议 | 增加 `VITE_AMAP_SECURITY_CODE` 配置，并在加载脚本前写入 `securityJsCode` |
| 涉及文件 | `frontend/src/components/AMapView.tsx`、前端环境变量配置 |

### 2.4 PDF 中文字体存在降级风险

| 项目 | 说明 |
|------|------|
| 现状 | PDF 导出优先注册 `simsun.ttc`；注册失败时降级到 `Helvetica` |
| 影响 | 没有宋体字体文件的环境中，中文内容可能显示异常或乱码 |
| 建议 | 项目内置可用中文字体，或在部署文档中明确字体安装要求 |
| 涉及文件 | `backend/api/trips.py`、部署说明文档 |

### 2.5 真实外部服务联调仍需验证

| 项目 | 说明 |
|------|------|
| 现状 | 测试大量使用 Mock，能验证解析逻辑，但不能保证真实 DeepSeek、高德 POI、高德路线、天气接口都能稳定返回预期格式 |
| 影响 | 演示环境可能出现 API Key、额度、网络、字段格式差异导致的运行问题 |
| 建议 | 准备一套真实 Key 的本地联调清单，至少覆盖注册登录、景点搜索、完整规划、保存行程、导出 PDF |
| 涉及文件 | `backend/services/amap.py`、`backend/services/weather.py`、`backend/agents/*.py`、`.env` |

## 三、建议优先级

| 优先级 | 问题 | 理由 |
|--------|------|------|
| P0 - 必须 | 处理 `TripDetail.tsx` 未使用变量和地图未展示问题 | 可能直接影响前端构建，并影响路线地图展示完整性 |
| P1 - 重要 | 补齐高德 JS 安全密钥配置 | 地图功能依赖外部配置，演示时容易暴露 |
| P1 - 重要 | 做一次真实外部服务端到端联调 | 多 Agent 项目的核心价值依赖真实 LLM 和外部 API |
| P2 - 一般 | 改进 PDF 中文字体方案 | 提升导出文件稳定性和展示质量 |
| P2 - 一般 | 增加前端构建/页面级测试 | 降低后续改动破坏 UI 的风险 |

---

## 四、验收建议

1. 运行后端测试，确认 API、CRUD、Agent Mock 测试通过。
2. 运行前端构建，确认 TypeScript 严格检查通过。
3. 使用真实环境变量启动前后端，完成一次从“对话规划 → 保存行程 → 查看详情 → 导出 PDF”的完整流程。
4. 用一个包含多个景点的行程验证地图、天气、预算、路线对比是否都能在页面中正确展示。
